Connection

The address of your Vikunja instance, without a trailing slash.

Create an API token in Vikunja under Settings → API Tokens. Give the token at least these permissions:

  • projects — read_all
  • tasks — read_all, create, update
  • other — user

If you use the Quick Add Magic syntax in the popup (*label, +project, !priority, @assignee), also grant labels read_all & create, tasks_labels create, and projects_users read_all.

Defaults

Tasks added from the popup and the capture window default to this project.

New tasks get a due date of today (at Vikunja’s nearest-hour time).

Used for the popup task list. Manual sorting needs a default project (Vikunja only orders by position inside a project view); otherwise the list falls back to newest first. You can change the order and direction from the popup.

When enabled, the sort you pick in the popup is stored locally in the extension and overrides this default.

Applied to the popup task list. Setting a custom filter replaces the default done = false filter (which hides completed tasks). See vikunja.io/docs/filters.

Integrations

Add a Matrix Element web instance to get an “Add to Vikunja” button on every message. The extension asks for permission to read the page, then adds the task through your Vikunja connection.

    After a message is added as a task, Element reacts to it with 📝 so everyone in the room can see it was captured. The reaction is sent by Element itself using your logged-in session.
